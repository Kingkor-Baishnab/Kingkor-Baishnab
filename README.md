1. Web Application VAPT – Altoro Mutual Banking Platform
Description: Conducted a comprehensive Vulnerability Assessment and Penetration Testing (VAPT) on the Altoro Mutual online banking web application following the OWASP Top 10 standard. The assessment was performed using Black-Box testing methodologies to evaluate the overall security posture of the platform.

Tools Used: Nmap (Port & Service Enumeration), Gobuster (Directory Brute-forcing), sqlmap (Automated SQLi Assessment), Wafw00f (WAF Detection), WhatWeb, and Linux Command-Line utilities (ping, curl).

Key Findings & Exploitation Proof-of-Concepts (PoCs):

SQL Injection (Critical): Successfully bypassed the authentication mechanism via the login portal (/login.jsp) using an authentication bypass payload (' OR 1=1 --), gaining administrative session access

Reflected Cross-Site Scripting (High): Identified an un-sanitized input field in the search bar component, successfully executing JavaScript code (<script>alert(document.cookie)</script>) to simulate session hijacking.



Broken Authentication (Medium): Exploited verbose server error messages to enumerate and confirm valid usernames (e.g., admin) within the database.
Sensitive Data Exposure & Misconfiguration (Medium/Low): Intercepted cleartext transmission over insecure HTTP protocol and mapped directory structures due to missing server hardening.

Outcome: Prepared a comprehensive, professional VAPT report detailing threat impacts, CVSS severity ratings, and actionable technical remediation guidelines (such as implementing Parameterized Queries, output encoding, and SSL/TLS deployment) to protect backend infrastructure.
